# WarriorRPG

A simple game created as part of the [Unreal Engine 5 C++: Advanced Action RPG](https://www.udemy.com/course/unreal-engine-5-advanced-action-rpg) course
to explore the GameplayAbilitySystem and MeleeCombatSystem

## Tech Stack
- Unreal Engine 5
- C++
- Blueprints
- Gameplay Ability System
